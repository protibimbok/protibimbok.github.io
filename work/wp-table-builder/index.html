WP Table Builder

Drag-and-drop tables for WordPress: pricing, comparison and Amazon product tables. I built its AI assistant, which creates and edits tables from plain language, and a standalone build of the editor that runs without WordPress.

The AI assistant creates, modifies and manages tables from a plain-language prompt, using the site owner's own provider key. Most of the work went into making LLM output reliable enough to ship inside a plugin installed on tens of thousands of sites.

The standalone build runs the real editor in a browser tab with no WordPress behind it. It's embedded live on the home page.
