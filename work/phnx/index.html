phnx

A PHP + Nginx local development manager. One command serves a Laravel, WordPress or plain PHP project at http://<name>.test, setting up the nginx site, PHP-FPM pool, /etc/hosts entry, MySQL/MariaDB or PostgreSQL database, plus Composer, WP-CLI and phpMyAdmin/phpPgAdmin. Runs on Linux and macOS.

  $ phnx site add wpdc --wp
  ✓ nginx  ✓ php-fpm  ✓ hosts  ✓ mysql
  → http://wpdc.test
