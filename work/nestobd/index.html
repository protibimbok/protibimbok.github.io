~/src/nestobd · Laravel · React

Nesto

Distribution management for a wholesale business: warehouse stock, bulk orders from sales agents, deliveries to dealers with drivers and returns, payments and SMS. Nine Laravel modules on my own laramod, with a React 19 admin and a Livewire storefront for retail.

The modules are Product, Order, Agent, Dealer, Delivery, Finance, Identity, Notification and Storefront. Stock batches go into the warehouse, approved sales agents place bulk orders, and deliveries carry orders to dealers, with drivers, returns and a ledger of transactions.

Stock allocation and its reversal run as MySQL stored procedures, so a delivery or an accepted order claims stock atomically. When stock runs out, the request is refused.

Each module ships an ai-workflow README that tells coding agents its purpose, public surface and conventions, so agents can work in one module without breaking the others.
